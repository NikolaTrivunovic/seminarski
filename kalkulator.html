Kalkulator Troškova Instalacije

⚛

React je primenjen na ovoj stranici — kalkulator.html

Kalkulator ispod nije pisan običnim HTML-om, već je React komponenta <KalkulatorTroskova />. React je iscrtava u prazan element <div id="reakt-koren"></div> pozivom ReactDOM.createRoot(...).render(...), pa je sve unutar isprekidanog okvira generisao React, a ne autor rukom u HTML-u.

  • Stranica sa React-om: jedino kalkulator.html; ostale stranice sajta rađene su čistim HTML-om, CSS-om i JavaScript-om.
  • Korišćene biblioteke: assets/reakt/reakt.razvojna.js, assets/reakt/reakt-dom.razvojna.js i assets/reakt/babel.prevodilac.js.
  • Stanje komponente: šest React.useState promenljivih — kvadratura, broj prostorija, četiri modula i izračunata cena.
  • Reaktivnost: pri svakoj promeni klizača, polja ili čekiranja React sam ponovo iscrtava komponentu, bez ručnog menjanja DOM-a.

Izračunajte okvirnu cenu opreme i instalacije smart home sistema prilagođenog vašim potrebama.
